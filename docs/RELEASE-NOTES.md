Cliente Windows de PPCM Mantenimiento.

- Windows 10/11 de 64 bits, con instalación para el usuario actual.
- Incluye su propio entorno de ejecución: no requiere Node.js ni Python.
- Se conecta al dashboard publicado; requiere internet y una cuenta habilitada.
- La URL puede estar preconfigurada o introducirse al abrir el cliente por primera vez.
- Los datos y las credenciales de la base de datos no se incluyen en el instalador.

Este instalador no tiene certificado de firma de código. Windows puede identificar el editor como desconocido. El archivo `client-manifest.json` incluye su hash SHA-256 para verificar la descarga.
